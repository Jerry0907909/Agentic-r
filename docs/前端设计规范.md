# 前端设计规范 v1.1

## 目标与边界

面向课程演示中的普通用户、医学生和验收方。界面优先让用户明白“能问什么、当前使用哪种能力、回答依据是什么”。保留两个并列且同等级的问答入口，不改变 `/api/ask` 与 `/api/ask_graph` 的契约，不增加登录系统。

## 信息架构

- 顶栏提供两个同级入口：`医疗健康问答`（`rag`）和 `知识图谱查询`（`graph`）。两者都可直接进入，不隐藏为高级模式。
- `医疗健康问答` 面向有症状、疾病、用药或日常健康困扰的普通用户，底层仅检索医学文档；说明为“咨询症状、疾病、用药与健康问题”。`知识图谱查询` 仅查询图谱，说明为“查询疾病、症状、药物、检查与科室关系”。移动端可使用短名称“健康问答 / 图谱查询”。
- 用户任务文案不得使用“学习医学资料”“从资料中了解”等表达。医学资料是回答依据，只在来源和可信度说明中出现，不作为用户访问产品的目的。
- 侧栏默认显示所有会话，按更新时间分组；每项显示模式标签。只有点击侧栏历史项才加载历史消息，并自动切换至该会话所属模式。桌面端支持展开与折叠，折叠状态不得影响会话选择和新建对话。
- 点击顶部任一模式入口都进入该模式的全新空白页，清除该模式当前选中会话、临时消息和草稿，但不删除历史数据；即使点击当前已激活的模式，也执行同样的新页面行为。顶部入口不得自动恢复上次选中的历史会话。
- 新建会话使用当前入口；已经创建的会话始终保持其 `agent_type`，不允许在另一模式续聊。流式输出期间不得切换模式或重置当前页面；选择历史会话前先中止当前流。
- API 的 `message_count` 统计用户消息与助手消息总数。界面不得直接显示“几条消息”，必须换算为 `ceil(message_count / 2)` 并显示“几轮对话”；一问一答显示为“1 轮对话”。
- 空状态提供与当前模式匹配的主标题和示例问题。单次回答只能出现当前模式对应的来源：`rag` 仅显示“医学资料”，`graph` 仅显示“知识图谱”；图谱来源不显示相似度。
- `health` 仅用于开发与运维诊断，不在面向用户的顶栏展示运行环境或服务状态。模拟回答仍必须明确标识 Mock，避免被误认为真实医疗结论。

## 视觉语言

方向采用“温暖健康”，面向普通用户而非医生工作台。关键词：温和、可信、自然、清晰、内容优先。界面应让用户感到是在使用健康知识助手，不暴露 RAG、Neo4j、Token 等实现概念作为主要视觉信息。

### 色彩令牌

- 浅色背景使用暖米白 `#F7F5EF`，卡片使用 `#FFFEFA`，主文字使用墨绿黑 `#25312B`，次级文字使用 `#5F6D65`，边框使用 `#DDE3D8`。
- 主品牌与主操作使用深鼠尾草绿 `#3F6F61`，白字对比度不低于 WCAG AA；浅鼠尾草色用于选中背景和温和提示。
- 暖橙 `#C97842` 只用于欢迎图形、引导箭头和非危险点睛，不用于大面积背景或长正文。
- 知识图谱来源使用青绿，医学资料来源使用灰蓝；两者同时配合图标和文字标签，不能只依赖颜色区分。
- 危险红只用于错误与删除，成功状态使用独立的自然绿。
- 深色主题使用暖黑绿表面与降饱和品牌色，不对浅色主题做机械反相；正文与背景仍需满足 4.5:1 对比度。

### 形态与层级

- 页面以米白环境底色、白色内容表面和轻边框分层，阴影仅用于浮层、输入区和关键卡片；禁止新拟态、玻璃拟态、霓虹发光和大面积科技渐变。
- 桌面端页面骨架使用 `264px 展开侧栏 / 72px 折叠图标栏 + minmax(0, 1fr) 主内容列`。侧栏宽度变化时，顶栏品牌列必须同步变化，主内容自动占满剩余空间，不保留空白列。宽桌面（≥1280px）的模式入口以主内容列而非整个视口居中；主题按钮对齐主内容列右侧 24px 边距。768—1279px 优先保证模式入口和主题按钮不重叠、不溢出。
- 顶栏所有一级区域垂直居中并使用一致的 48px 内容高度，不得用独立最大宽度容器造成品牌、模式入口和主内容中心线错位。
- 两种问答能力必须使用同尺寸、同层级的分段卡片呈现。选中态同时使用底色、边框、图标和说明文字，不把任一模式降级为“高级功能”。
- 顶栏采用单行文字层级：品牌区只显示“医知助手”，两个能力入口只显示模式名称，不在名称下方显示品牌副标题、能力说明等小字。删除次级文字后，图标与主文字必须在各自组件内垂直居中。
- 品牌图标与能力图标的外框统一使用主品牌绿，不使用蓝色或另设强调色，保证首页识别元素与主操作配色一致；图标容器外不添加无信息含义的圆点、角标等装饰。
- 品牌“医知助手”使用心电心形图标；`医疗健康问答` 的顶部入口和空状态统一使用听诊器图标；`知识图谱查询` 统一使用关系网络图标。品牌标识与能力标识分工明确，不互相替换。
- 品牌面向用户显示“医知助手 / 可信医疗知识问答”；`Agentic RAG` 只可作为课程演示的次级技术说明。
- 两种模式的空状态仅显示能力图标、任务导向主标题和三条示例问题；不显示重复的模式小标题、说明段落或卡片底部的参考依据与医疗提示行。图标至主标题间距为 16px，标题区至卡片间距为 24px（桌面 32px）；移除内容不保留占位，整体在可用区域内居中，移动端从顶部排列。
- 会话区正文最大阅读宽度约 760px；用户消息使用鼠尾草绿气泡，助手回答使用白色卡片，来源和模型用量下沉为次级信息。
- 侧栏只承担新建与历史会话管理，降低其视觉权重。桌面展开态宽度为 264px；折叠态保留 72px 图标栏，显示新建按钮和带 Tooltip 的历史会话模式图标，隐藏日期、标题、轮次、重命名、删除与底部说明。折叠态历史入口按“医疗健康问答在上、知识图谱查询在下”排列，同类会话保持最近更新优先。移动端始终作为 264px 可关闭抽屉出现，不继承桌面折叠视觉。
- 提问区采用单层容器边界：外层圆角容器承担边框与焦点反馈，内部文本域不显示独立边框、矩形轮廓或阴影，避免形成双边框。
- 提问区不显示模式名称、快捷键说明和 `0/2000` 字数计数等底部辅助行；仍保留接口要求的 2000 字输入上限。删除辅助行后，麦克风、文本域和发送/停止按钮在单层容器内垂直居中，不保留空白占位。

### 排版、间距与交互

- 对话区不展示会话标题、模式和轮次组成的顶部横幅。侧栏历史项的“健康问答”和“图谱查询”标签统一使用浅主品牌绿底与深主品牌绿文字，标签与轮次不拆字换行；操作按钮位于标题行右侧，不挤压下方标签行。

- 主页示例卡片从下方 18px 缓缓浮现，每张持续 1000ms、相邻间隔 200ms，整组约 1.4 秒。透明度和位移仅设起止关键帧，使用一段连续的缓入缓出曲线，避免中间关键帧重复减速造成停顿；仅播放一次，切换模式重新播放，输入草稿不触发重播。动效不改变布局尺寸，键盘聚焦时立即显示；系统启用减少动态效果时直接显示所有卡片。

- 新建空白主页的输入框位于主标题下方、示例卡片上方，与欢迎内容整体居中；输入框和卡片共用内容宽度。发送首条消息后，或选中任意历史会话（包括加载中、空会话），输入框位于会话区域底部。切换模式或新建对话后恢复居中布局；同一页面只渲染一个输入框。

- 顶栏与侧栏采用无分隔线布局：不显示顶栏底线、品牌列右线、侧栏右线及侧栏页脚顶线，避免交叉线形成格子感；通过背景和留白区分区域。折叠按钮仍对齐品牌列右边界，按钮、卡片及输入容器自身的边框保留。

- 桌面侧栏折叠后隐藏顶栏品牌 Logo 和品牌名，仅保留展开按钮，并将按钮居中放置在 72px 图标栏内；重新展开后恢复品牌显示与分隔线上的折叠按钮。移动端品牌展示不受桌面折叠状态影响。

- 使用系统中文无衬线字体栈；正文至少 14px、输入文字在移动端至少 16px，行高 1.6—1.75；辅助文字原则上不低于 12px。
- 间距基准为 4px，常用 8 / 12 / 16 / 24 / 32 / 48px；卡片圆角以 16px 为主，输入区可使用 20px，标签使用全圆角。
- 主要操作和移动端触控目标至少 44×44px；键盘焦点可见，交互状态不能只用颜色表达。
- 桌面侧栏折叠按钮放在顶栏品牌 Logo 同一行、品牌列右侧分隔线上，不放在侧栏新建按钮上方；使用明确的侧栏开合图标、44×44px 点击区域，并提供“折叠会话列表 / 展开会话列表”的可访问名称。展开态“新建对话”按钮占满侧栏内容宽度。折叠状态写入 `localStorage` 的 `agentic-rag-sidebar-collapsed`，刷新后保持。宽度切换使用 200ms 左右的平滑过渡，并遵循 `prefers-reduced-motion`。
- 状态切换使用 150—250ms 的颜色、透明度和轻微位移动效，不改变布局尺寸；遵循 `prefers-reduced-motion`。
- 空白欢迎页不展示医疗免责声明；回答中的医疗提示不受此次空状态精简影响。

## 组件职责

- `Header`：品牌、桌面侧栏展开/折叠控制、同级模式切换和主题控制；不展示模式副说明、Mock、接口健康度等次级信息。
- `Sidebar`：全量会话、模式标签、日期分组、新建、重命名与删除；消费折叠状态但不放置折叠控制器。
- `EmptyState`：当前模式的图标、任务导向主标题和示例问题。
- `Composer`：语音输入、提问和停止生成；模式差异只通过输入占位文案表达，不增加底部辅助行。
- `MessageBubble` / `SourceCard`：回答正文、来源与用量的清晰层级。

## 验收

1. 点击两个顶部模式入口都会进入对应空白新页面，不自动显示历史；切换模式不会删除侧栏历史。
2. 侧栏显示两类会话，点击任一历史会话才加载消息并自动选中正确模式；一问一答显示“1 轮对话”。
3. 桌面侧栏默认 264px，可折叠为 72px；顶栏品牌列与主内容同步重排，刷新后保持折叠状态。折叠态仍可新建对话和选择历史会话。
4. 顶栏不显示 Mock 或服务健康状态；Mock 回答正文仍有清晰的模拟内容标识。
5. 375px、768px、1024px、1440px 宽度无水平溢出；移动端横屏可完成切换、提问和关闭侧栏；键盘可操作主要控件。
6. 后端测试、前端 lint 和 build 通过；Mock 与真实接口契约不变。
7. 顶栏品牌和模式入口均为单行主文字；输入区无底部辅助行，删除文字后组件内部仍垂直居中且无多余空白。
